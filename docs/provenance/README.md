# Reproduction provenance

This directory preserves the detailed handoffs from the June scratch rerun,
the July Alps rerun, and the local artifact audit. These files are evidence
and lab notes, not reviewer entry points. Some commands refer to superseded
campaign helpers or external scratch paths that are intentionally not part of
the clean branch.

Use the top-level `README.md`, `reproduce_quick.sh`, and `reproduce_full.sh`
for the supported artifact workflow. The consolidated scientific conclusions
and selected compact results are in `docs/REPRODUCTION_REPORT.md` and
`results/reproduced/`.
